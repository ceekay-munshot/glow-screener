# Glow Screener

Small-cap (₹200–2,000 Cr) equity research dashboard for **Glow Ventures**.

Fundamentals · Technicals · Macro · Sentiment & Liquidity scoring over a
screener.in-defined universe of Indian small-caps. Static dashboard
(`public/`) served by a Cloudflare Worker, with data refreshed automatically
by GitHub Actions scrapers.

- **Universe:** screener.in screen — market cap ₹200–2,000 Cr (~1,451 companies)
- **Skeleton:** replicated from the LKP screener framework; scoring rules unchanged
